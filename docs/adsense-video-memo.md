# 애드센스 승인 영상 메모 (외부 조언 + 판정)

출처: 사용자가 붙여넣은 유튜브 영상 요약 (원본 영상 미확인, 요약 기준 판정).
기준 충돌 시 `adsense-approval` 스킬(실측 게이트)과 구글 공식 문서가 우선.

## 영상 주장 요약

1. 뾰족한 마이너 주제 + AI로 제목 20~30개 확보
2. 카테고리 하나로 통일
3. 운영 중인 사이트처럼 세팅 (이미지·SEO 과도 집착 불필요)
4. 워드프레스 + 플러그인 AI 글쓰기, 표(Table) 활용
5. 반려 대응: 저가치 콘텐츠(꾸준 발행 후 재신청) / 사이트 행동(内外 링크 제거) / 서버 이슈(안정 호스팅) / 중복 계정
6. 첫날 10개 + 예약 발행으로 지속 업데이트처럼 / 여러 번 거절 시 도메인 변경

## 판정 (2026-09-24 실측 기준)

| 영상 주장 | 판정 | 이유 |
|---|---|---|
| 뾰족한 주제 | 이미 충족 | 워킹맘 15분 집밥 + 룰렛 도구, 제목 구체적. 유지 |
| 카테고리 통일 | 이미 충족 | 글 11개 전부 한식. 유지 |
| 운영 중인 사이트처럼 | 이미 충족 | about·privacy·terms·contact, 사이트맵, ads.txt, 서치콘솔 메타 있음 |
| 이미지 집착 불필요 | 기각 | 실사 사진이 오리지널리티 증거. 장당 300KB 이하 JPG 유지 |
| AI 대량 글쓰기 | 기각 | 승인 스킬 cookie-cutter 규칙(공통 어휘 80%+) 위반. 페르소나 실사 글 유지 |
| 내부 링크까지 제거 | 기각 | 글에 외부 링크 0개로 이미 충족. 내부 링크는 정상 사이트의 일부라 유지 |
| 예약 발행 위장 | 기각 | 날짜 위조. 실제 하루 1개·실제 발행일 유지 |
| 표 형식 가독성 | 차후 선택 | 신규 글에 한눈보기 표 1개 정도 허용. 기존 글 소급은 안 함 |
| 도메인 변경 | 기각 | 현 단계에서 사유 없음 |
